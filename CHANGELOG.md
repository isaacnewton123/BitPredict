# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **[Sats Vector Logo]**: Converted the uploaded Satoshi PNG mark into a vector SVG ([sats-logo.svg](frontend/public/brand/sats-logo.svg)) and integrated [SatsIcon.tsx](frontend/components/shared/SatsIcon.tsx) across pool volumes, order ticket inputs & payout estimates, trade tape, payout claims, and admin/oracle views.
- **[Direct Wallet & Hybrid Claims]**: Added client-side WebLN (`window.webln`) and NIP-47 NWC (`nostr+walletconnect://`) Lightning wallet integration in [lightning-wallet.ts](frontend/lib/lightning-wallet.ts), separated Nostr identity (`Sign In with Nostr`) from Lightning wallet connections in [AppHeader.tsx](frontend/components/layout/AppHeader.tsx) and [OrderTicketPanel.tsx](frontend/components/trading/OrderTicketPanel.tsx), replaced the LUD-16 form in [PositionsView.tsx](frontend/components/views/PositionsView.tsx) with [LightningWalletCard.tsx](frontend/components/views/LightningWalletCard.tsx) (featuring optional offline LUD-16 auto-payouts + Nostr `kind 0` `lud16` sync), and added direct 1-click wallet invoice claiming plus BOLT11 / LNURL-withdraw fallbacks in [ClaimPayoutModal.tsx](frontend/components/views/ClaimPayoutModal.tsx).
- **[Admin Console & Confirmation Modals]**: Separated operator/admin controls from the public UI into a dedicated `/admin` console (`frontend/app/admin/page.tsx`, `frontend/components/views/AdminConsoleView.tsx`, and modular `frontend/components/admin/{AdminDisputesPanel,AdminProposalsPanel,AdminFeedsOpsPanel}.tsx`) featuring dispute arbitration rulings (`ruleBackendDispute` -> `POST /api/v1/admin/disputes/:id/rule`), Track B oracle proposals/finalization, automated data-feed resolution, and showcase seeding; exposed `is_admin` on `POST /api/v1/auth/nostr`, `GET /api/v1/me`, and `PATCH /api/v1/me` (`app/src/routes/auth.ts`); and added a reusable accessible `ConfirmActionModal` (`frontend/components/shared/ConfirmActionModal.tsx`) across all critical admin rulings, oracle actions, market publishing, Lightning bet orders, proposal challenges, and payout claims.

### Changed

- **[Frontend Modularization]**: Refactored `frontend/components/BitPredictApp.tsx`, `frontend/components/MarketTradingView.tsx`, and removed monolithic `SecondaryViews.tsx` by extracting single-responsibility components into `frontend/components/layout/{route-utils,AppHeader,AppFooter,ToastStack}`, `frontend/components/markets/{MarketCard,MarketDiscoveryView}`, `frontend/components/trading/{ProbabilityChartCard,OutcomePoolsCard,MarketIntelligenceTabs,OrderTicketPanel}`, and `frontend/components/views/{CoverImageUploader,CreatorView,OracleConsoleView,PositionsView,HowItWorksView}`.
- **[Default Market Icons]**: Removed static `frontend/public/markets/*.svg` artwork and replaced default market cover thumbnails with crisp `react-icons` category icons via [MarketCover.tsx](frontend/components/shared/MarketCover.tsx), while keeping custom uploaded and HTTPS cover images intact (`resolveMarketImageUrl`, `safeImageUrl`).
- **[Structured Contract Display]**: Replaced raw `<pre>{JSON.stringify(...)}</pre>` blocks and internal API/backend/DB labels across `CreatorView`, `MarketIntelligenceTabs`, `OracleConsoleView`, `MarketDiscoveryView`, `PositionsView`, `MarketTradingView`, `HowItWorksView`, `AppFooter`, and `BitPredictApp` with the structured `OracleSpecSummary` component (`frontend/components/shared/OracleSpecSummary.tsx`) and user-facing oracle transparency copy.

### Added

- **[Trading UI & Media Uploads]**: Added authenticated multipart market cover image upload & static serving (`POST /api/v1/uploads/market-image`, `GET /api/v1/uploads/:filename` in `app/src/routes/uploads.ts`, optional `image_url` in `MarketSpecSchema` / `POST /api/v1/markets/draft`), confirmed trade tape & implied probability curve generation (`getMarketActivityFromDb` on `GET /api/v1/markets/:id`), updated `docs/openapi.json` (27 paths), added 9 custom vector category covers (`frontend/public/markets/*.svg`), added drag-and-drop cover image uploader + live spec sync to `CreatorView` (`frontend/components/SecondaryViews.tsx`), upgraded market discovery cards with cover thumbnails & mini semi-circle probability gauges (`frontend/components/BitPredictApp.tsx`), and replaced modal-only inspection with a full-page Polymarket/Binance-style Market Trading Terminal at `/m/[slug]` (`frontend/components/MarketTradingView.tsx`).
- **[AI / NVIDIA NIM]**: Added NVIDIA NIM (`https://integrate.api.nvidia.com/v1` OpenAI-compatible JSON chat completions defaulting to `nvidia/nemotron-3.5-lightning-30b-a3b`) across the AI Market Creator (`app/src/lib/ai/compiler.ts`), Market Insight generator (`app/src/lib/ai/insight.ts`), and Track B Evidence Summarizer (`app/src/lib/ai/evidence.ts`) via the shared `app/src/lib/ai/llm.ts` client (`AI_PROVIDER`, `NVIDIA_API_KEY`, `NVIDIA_BASE_URL`, `NVIDIA_MODEL`) with Google Gemini and deterministic fallbacks preserved, explicit schema guidance in `app/src/lib/ai/prompt-template.ts`, updated `app/.env.example` / `docs/14-env-and-api-keys.md`, and NVIDIA NIM unit tests.

## [Unreleased]

### Added

- **[Frontend & Env]**: Removed static mock markets/positions/compiler data from `frontend/` (`frontend/lib/bitpredict-data.ts`, `frontend/components/{BitPredictApp,SecondaryViews,MarketModals}.tsx`) and wired live Nostr login (NIP-07 / guest keypair via `nostr-tools`), market listing + auto-seed fallback, AI draft/publish, Lightning bet settlement, oracle console queue/ticks, and positions/payouts directly to the Elysia backend (`app/`); returned session `token` alongside the HTTP-only cookie in `POST /api/v1/auth/nostr` (`app/src/routes/auth.ts`); created `frontend/.env` and `app/.env`; and added `docs/14-env-and-api-keys.md` explaining how to populate every environment variable and obtain external API keys.
- **[Config]**: Added `frontend/.env.example` (`BACKEND_URL`, `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_APP_URL`, `NEXT_PUBLIC_NOSTR_RELAYS`), allowed tracking it in `frontend/.gitignore`, and wired `frontend/public/brand/` logos (`bitpredict-wordmark-light.png` and `bitpredict-logo.jpg`) into the frontend header, footer, and icons.
- **[Elysia & Scalar]**: Migrated the BitPredict backend from Next.js API routes to Bun + Elysia (`app/`) with `@elysiajs/openapi` (Scalar UI at `/openapi`, OpenAPI 3.1 JSON at `/openapi/json`) and `@elysiajs/cors`, organizing all REST endpoints into `app/src/routes/{auth,markets,settlement}.ts` + `app/src/app.ts` / `app/src/index.ts`, replacing Next.js `cookies()` / `server-only` in `app/src/lib/auth/server.ts`, `app/src/lib/db/client.ts`, and `app/src/lib/markets/queries.ts`, introducing `FetchLike` for Bun/Node compatibility, generating `docs/openapi.json`, adding root `scalar.config.json`, and adding `app/src/lib/__tests__/elysia-api.test.ts`.
- **[Structure]**: Organized the repository cleanly into `frontend/`, `app/`, and `docs/`, relocating backend API routes, core domain/AI/Nostr/Lightning/Oracle libraries, Drizzle migrations, SQLite data, Vitest suites, and `.env.example` into `backend/` (port `3001`), moving `kraken/DESIGN.md` to `frontend/DESIGN.md`, `public/brand` to `frontend/public/brand`, and `conceps.md` to `docs/00-concept.md`, removing superseded root frontend/template files, configuring `frontend/next.config.ts` `/api/v1/*` proxy rewrites to `BACKEND_URL || http://localhost:3001`, and stripping UI scaffolding from `backend/src/app/{layout,page}.tsx`.
- **[Frontend]**: Migrated the BitPredict frontend to `frontend/` (`frontend/app/`, `frontend/components/`, `frontend/lib/bitpredict-data.ts`) with the Kraken-inspired light design from `template.html` (IBM Plex Sans typography, crisp `#ffffff` canvas, `#dedee5` borders, `#7132f5` purple CTAs, and `#149e61` outcome accents), configuring Tailwind v4 `@theme` tokens (`frontend/app/globals.css`), `turbopack.root` + optional `BACKEND_URL` proxy rewrite (`frontend/next.config.ts`), multi-view shell (`BitPredictApp.tsx`, `SecondaryViews.tsx`, `MarketModals.tsx`) with sticky header/mobile tabs, live stats badges, 9-category bar, AI Prompt-to-Oracle Studio, Dual-Track Oracle Console, NWC/LUD-16 Positions & Payouts, Contract/AI Insight & WebCrypto SHA-256 inspector, and App Router pages (`/`, `/create`, `/docs`, `/oracle`, `/profile`, `/c/[slug]`, `/m/[slug]`).
- **[Demo & Polish]**: Phase 8 Polish, Insights & Demo Seeding — AI Market Insight Card (`src/lib/ai/insight.ts`, `GET /api/v1/markets/[id]/insight`, `src/components/markets/MarketInsightCard.tsx`, wired into `src/app/m/[slug]/page.tsx`) with `ai_runs` caching and non-binding disclaimer; expanded rule compiler (`src/lib/ai/rule-compiler.ts`) routing explicit `coingecko`, `thesportsdb`, and `opendota` prompts to Track A; idempotent 3-user / 6-market showcase seeder with balanced double-entry ledger (`src/lib/demo/seed.ts`, `POST /api/v1/demo/seed`); mobile header navigation (`src/components/layout/Header.tsx`) and empty-state **Load Demo Markets** control (`src/components/markets/SeedDemoButton.tsx`, `src/components/markets/MarketGrid.tsx`); and Phase 8 tests for provider routing, recorded fixtures, AI insights, and idempotent seeding (`src/lib/oracle/__tests__/demo-and-providers.test.ts`).
- **[Oracle Track B]**: Phase 7 Track B Nostr Optimistic Oracle — Kind `30080` dispute event builder (`buildDisputeEvent` in `src/lib/nostr/events.ts`), AI Evidence Summarizer (`src/lib/ai/evidence.ts`), Track B proposal/dispute/arbitration & conflict-of-interest guards (`src/lib/oracle/track-b-repo.ts`, plus bet-time signer check in `src/lib/payments/bet-repo.ts`), automatic challenge-window finalization in `runOracleTick` (`src/lib/oracle/worker-repo.ts`), `/api/v1/oracle/queue`, `/api/v1/markets/[id]/proposals`, `/api/v1/markets/[id]/disputes`, and `/api/v1/admin/disputes/[id]/rule` endpoints, `/oracle` Signer Console UI (`src/app/oracle/page.tsx`, `src/components/oracle/SignerConsoleClient.tsx`) + Track B proof/challenge controls (`src/components/markets/OracleProofPanel.tsx`, `src/components/layout/Header.tsx`), and 3 Track B conflict/settlement/arbitration tests (`src/lib/oracle/__tests__/track-b-oracle.test.ts`).
- **[Settlement]**: Phase 6 Settlement & Automatic Payouts — Millisatoshi parimutuel split & one-sided/VOID refund calculator (`computeMarketSettlement` in `src/lib/domain/pool.ts`), outgoing LNURL-pay invoice requests & LNbits/demo payments (`requestInvoiceFromLightningAddress`, `payLightningInvoice` in `src/lib/payments/lnbits.ts`), Nostr Kind `1` Settlement Note builder (`buildSettlementNoteEvent` in `src/lib/nostr/events.ts`), automatic settlement & 3-retry → `CLAIMABLE` fallback repository (`src/lib/payments/settlement-repo.ts`) wired into the Oracle Worker (`src/lib/oracle/worker-repo.ts`), `/api/v1/me/payouts`, `/api/v1/payouts/[id]/claim`, and `/api/v1/payouts/[id]/lnurlw` endpoints, **My Positions & Payouts** UI with preimage proofs & instant claiming (`src/components/auth/ProfileClient.tsx`, `src/components/markets/OracleProofPanel.tsx`, `src/components/layout/Header.tsx`), and 5 settlement/payout tests (`src/lib/payments/__tests__/settlement.test.ts`).
- **[Oracle Track A]**: Phase 5 Track A Auto-API Oracle — Deterministic JSON `value_path` extractor & decimal condition evaluator (`src/lib/oracle/evaluator.ts`), platform oracle keypair (`getPlatformOracleKeypair` in `src/lib/nostr/keys.ts`) & Kind `30079` outcome attestation builder (`buildOutcomeAttestationEvent` in `src/lib/nostr/events.ts`), Track A resolver & lifecycle worker tick (`src/lib/oracle/worker-repo.ts`) handling `OPEN` → `CLOSED` → `RESOLVING` → `RESOLVED` / 24h `VOID` with `oracle_proofs` SHA-256 commitments, `/api/v1/markets/[id]/proof` & `/api/v1/oracle/tick` endpoints, interactive Proof Viewer + live countdown + demo fast-forward resolver (`src/components/markets/OracleProofPanel.tsx`), and 5 Track A oracle tests (`src/lib/oracle/__tests__/track-a-oracle.test.ts`).
- **[Lightning]**: Phase 4 Lightning Betting — LNbits REST API + `DEMO_MODE` simulated invoice adapter (`src/lib/payments/lnbits.ts`), in-process SSE pool event bus (`src/lib/payments/events.ts`), parimutuel payout estimator (`estimatePotentialPayoutMsat` in `src/lib/domain/pool.ts`), atomic bet placement, idempotent webhook confirmation, double-entry ledger updates, and late-payment refund queuing (`src/lib/payments/bet-repo.ts`), `/api/v1/markets/[id]/bets`, `/api/v1/webhooks/lnbits`, `/api/v1/bets/[id]`, `/api/v1/me/positions`, and `/api/v1/markets/[id]/stream` SSE endpoints, interactive live-updating bet slip with QR code, WebLN/NWC 1-click pay, and demo payment simulation (`src/components/markets/MarketBettingPanel.tsx`), plus 5 betting & ledger tests (`src/lib/payments/__tests__/betting.test.ts`).

### Changed

- **[Brand]**: Project renamed from "dakar-BTC" to **BitPredict** in `README.md` and the product docs.

### Fixed

- **[Compiler]**: Word-bounded `k` and `m` multipliers (`k\b`, `m\b`) in `src/lib/ai/rule-compiler.ts` so durations like `"45 minutes"` are not parsed as `45,000,000`, plus added symbolic operator (`>=`, `<=`, `==`, `>`, `<`) parsing.
- **[Settlement]**: Derived pubkey directly from `opts.platformSecretKey` in `settleMarketAndDispatchPayouts` (`src/lib/payments/settlement-repo.ts`) and forwarded optional `platformSecretKey`, `requestInvoiceFn`, and `payInvoiceFn` overrides in `resolveTrackAMarket` (`src/lib/oracle/worker-repo.ts`).
